# 设置与操作指引

**状态**：现行架构
**最后更新**：2026-10-22

---

## 1. 背景

1. 平台、网络、窗口、快捷键混在少数页面里，主播找不到。
2. 首次启动只有静态说明，无法指出控件位置。
3. 设置项卡片结构不一致，视觉上像不同系统拼起来。

### 1.1 修改历史

| 日期 | 变更 | 原因 |
|---|---|---|
| 2026-10-22 | 首次定稿 | 7 个 tab、统一卡片、spotlight 指引 |

---

## 2. 结构

设置页 tab：

```
平台连接 / 网络 / 外观 / 窗口 / 快捷键 / 数据 / 关于
```

- 外观：主题、弹幕栏模式、平台显示、结果展示。
- 数据：存储、日志等级、收集日志。
- 关于：操作指引重播、最近更新、GitHub。

## 3. 操作指引

- 首次启动读 `config.ui.onboardingDone=false`。
- 5 步 spotlight：设置入口 → 工具切换器 → 弹幕栏 → 连通性测试 → 快捷键。
- 每步高亮真实 DOM，可自动切页/切 tab；卡片贴在目标旁。
- 跳过/完成写回 `onboardingDone`；清除数据后重新出现。

## 4. 改动时的检查点

- 新设置项是否放进正确 tab，而不是继续堆在外观？
- 卡片是否使用统一的 `card` + header 结构？
- 新控件是否有 label 与键盘焦点？
- 操作指引的目标 selector 是否仍存在？
- 主题/日志设置是否同步到 snapshot？

## 5. 已知取舍

| 取舍 | 代价 |
|---|---|
| 7 个 tab | 小屏幕上需要横向滚动 |
| spotlight 依赖 DOM 选择器 | 控件重命名时必须同步改指引 |
