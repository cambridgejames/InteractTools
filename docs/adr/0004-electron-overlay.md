# ADR-0004：结果小窗用 Electron 透明窗，不内置 HTTP 服务

- 状态：已接受
- 日期：2026-10-18

## 背景

直播场景通常有两种上屏方式：OBS 浏览器源（需要一个 HTTP 页面）或窗口捕获（捕获一个原生窗口）。项目要求开箱即用、单机运行。

## 决策

最终结果使用独立的 Electron `BrowserWindow`：透明、无边框、置顶、跳过任务栏；窗口只展示结果，不播放动画。OBS 通过窗口捕获采集。第一版不启动本地 HTTP 服务。

## 后果

- 不需要端口、防火墙、证书，也不增加一个常驻服务。
- OBS 窗口捕获对透明窗口的支持依赖版本；需要在 `docs/testing.md` 记录验证矩阵。
- 动画在控制面板内，结果窗只负责最终结果和彩带烟花；决策见 ADR-0005。
- 若未来需要浏览器源，新增一个 Surface 即可，工具与内核不变。
