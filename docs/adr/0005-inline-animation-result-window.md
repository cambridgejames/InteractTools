# ADR-0005：动画在工具面板内，结果再弹窗

- 状态：已接受；其中“结果用原生小窗”部分由 ADR-0006 调整
- 日期：2026-10-19

## 背景

把整套转盘/骰子动画放进独立结果窗，用户看不到“设置页面里的转盘正在转”，还要先弹窗再开始动画。用户要的是：动画就在当前工具面板内连续发生，停稳后结果再弹窗。

## 决策

- 骰子投掷动画发到 `DicePanel`：`dice.roll` 走控制台 IPC，面板用 Three.js 就地回放录制帧。
- 转盘旋转由 `WheelToolView.currentSpin` 驱动 `WheelPanel`：CSS `rotate` 原地旋转，指针和中心保持不动。
- 动画结束、结果落定后，工具发 `dice.result` / `wheel.result` 到控制台 ResultOverlay；弹窗只显示结果卡和彩带烟花，手动关闭（载体由 ADR-0006 调整）。
- `SurfaceHost` 全部发控制台：动画给工具面板，结果给 ResultOverlay。

## 后果

- 面板必须自己具备动画能力；新工具需要同时实现面板动画和结果 payload。
- 结果弹窗只承载最终结果，不再有“弹窗里重播整套动画”的割裂感。
- OBS 直接采集控制台窗口即可包含结果弹窗。
