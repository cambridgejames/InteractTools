# ADR-0002：物理在主进程执行，overlay 只回放

- 状态：已接受
- 日期：2026-10-18

## 背景

结果窗口需要播放真实的骰子滚动动画，同时最终点数必须与记录一致。若渲染进程自己跑物理，主进程和 overlay 可能因为浮点、帧率或版本差异得到不同结果。

## 决策

主进程用 cannon-es 以固定步长完成模拟，记录结果面、seed 与逐帧位姿（60Hz，位置 + 四元数），把这份数据交给 overlay。overlay 用 Three.js 按帧回放，不运行物理。

## 后果

- 结果与画面只有一个事实源，可直接单测。
- overlay 实现简单，不需要引入 cannon-es，也不需要同步两个物理世界。
- 单次载荷约 300–500 帧 × 7 个数字，结构化克隆开销可接受。
- 动画不能动态改变时间流速以外的物理行为；这是有意的取舍。
