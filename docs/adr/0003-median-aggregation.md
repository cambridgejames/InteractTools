# ADR-0003：力度默认取中位数

- 状态：已接受
- 日期：2026-10-18

## 背景

观众通过弹幕设置 0–100 的力度，最终需要一个代表「全场力度」的值。均值容易被少量极端值拉偏；中位数对异常值稳健，但会忽略整体偏移。

## 决策

默认使用中位数；配置可切换 `mean` 与 `trimmedMean`（两端各去掉 10%）。结果面板同时展示 count、min、max、mean、median、trimmedMean。

## 后果

- 一个刷 0 或 100 的观众无法单独决定结果。
- 人数很少时中位数与均值差异明显，UI 需要展示样本数，避免误读。
- 聚合逻辑是纯函数，三种算法共用同一组测试向量。
