# ADR-0006：结果弹窗改为应用内，便于 OBS 采集

- 状态：已接受
- 日期：2026-10-19

## 背景

原方案把最终结果放在独立透明小窗，OBS 需要额外窗口采集源，控制台和结果窗分散；用户希望 OBS 直接采集应用窗口就能包含结果。

## 决策

- 结果 presentation 全部发给控制台窗口，不再创建 ResultWindow。
- 控制台用 ResultOverlay 覆盖应用显示结果卡；彩带烟花画在控制台窗口内。
- 工具面板内动画保持不变：骰子 3D、转盘 CSS、投票实时票数。
- 关闭走同一个 overlay:dismissed IPC；删除 result preload、result renderer 和 ResultWindow。

## 后果

- OBS 只需采集「互动工坊」主窗口。
- 不再有独立结果窗的透明/阴影/多显示器问题。
- 结果弹窗会覆盖控制台 UI；如果以后要纯净上屏，需要另加“舞台模式”。
- 结果窗尺寸不再独立，弹窗卡片按控制台窗口居中。
