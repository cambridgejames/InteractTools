# 使用说明

## 1. 运行

要求：Windows 10/11，Node.js ≥ 22.12。

```bash
npm install
npm run dev
```

首次运行会在 `%APPDATA%\interact-tools`（Electron userData）创建 `config.json` 和 `history/dice.json`。

如果 Electron 被当成 Node 启动（终端里出现 `Cannot read properties of undefined (reading 'requestSingleInstanceLock')`），先清掉环境变量 `ELECTRON_RUN_AS_NODE` 再运行：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm run dev
```

## 2. 本地模拟：先跑通全链路

1. 打开「平台连接」，确认「本地模拟」是「已连接」；没有就打开「启用模拟源」开关。
2. 回到「控制台」，选骰子面数、倒计时、聚合方式；配置输入会自动保存，不需要手动点保存。右侧「合力」表会随力度实时增长，说明力度决定抛投强度，最终点数仍由物理碰撞决定。力度只接受 0–100 的整数，越界、负数、小数和非数字会被忽略，并在弹幕栏提示一次。不等待弹幕时点「直接投掷」，会跳过收集并使用随机 0–100 力度。右侧实时弹幕栏可完整显示/折叠/隐藏，去「平台连接」或「设置」时也能看到观众在说什么；消息多时自动贴底，用户上翻后不会被强制拉回。
3. 点「开始收集」。
4. 在右侧弹幕面板发送 `!力度 80`，或点工具面板顶部的「测试命令」chip。
5. 倒计时结束会自动投掷：骰子从中央发射台向上弹射，力度越大冲得越高、转得越快，镜头随之上升后拉；100 力度时骰子几乎冲到画面上沿。停稳后在控制台内弹出结果弹窗，带彩带烟花。看完点右上角关闭、点遮罩或按 Esc，不会自动消失。

模拟观众默认每 3 秒发一条消息。没有工具在收集时只发普通聊天/礼物；骰子或投票进入收集阶段后，才会按当前工具发布命令提示，约 70% 注入对应命令。可以在「平台连接」里关掉或调整间隔。

### 转转盘（主播手动）

1. 在控制台顶部工具切换器选择「转转盘」。
2. 在右侧编辑格子内容（每行一个，2–16 个），设置旋转时长。
3. 点「开始旋转」。主播手动触发，**没有弹幕命令、没有倒计时**；选项直接写在扇形上并跟着盘面旋转。
4. 面板里的转盘原地旋转 5 秒后停住，结果格与顶部指针对齐；随后在控制台内弹出结果弹窗。
5. 「预览」不写入历史，用来调样式。

### 弹幕投票

1. 在控制台顶部工具切换器选择「弹幕投票」。
2. 编辑问题、选项（每行一个，2–8 项）和倒计时（5–300 秒）；输入会自动保存。默认每人只计第一票；需要让观众改票时打开「允许改票」，此时后票覆盖前票。
3. 点「开始投票」。观众发送 `!投票 1` 或 `投票 选项文字`；同一观众以最后一票为准。
4. 投票中左侧顶部会显示 64px 大倒计时和进度条；倒计时结束或点「提前结束」后，面板显示实时票数与并列最高票，同时在控制台内弹出结果弹窗。
5. 0 票时显示「无人投票」，不伪造赢家；「预览」不写入历史。

## 3. 命令

```bash
!力度 80
#力度 80
力度80
力度：80
POWER 60
!投票 1
投票 方案 A
vote 3
```

- 力度值必须是 0–100 的整数；越界会被丢弃，不会截断。
- 投票支持 1-based 序号和选项文字；越界或不存在会被忽略。
- 同一观众在一轮里只算最后一条有效指令。
- 只认消息开头的命令，聊天里顺口说「力度」「投票」不算。
- 默认聚合是中位数；可在「聚合」里切换平均值 / 截尾均值。

## 4. B站

1. 在「平台连接」里填写直播间房间号（短号或真实房间号都可以）。
2. 点「连接 B站」。
3. 状态变为「已连接」后，弹幕会进入事件流；力度命令只在倒计时期间生效。

第一版是**匿名只读**：不登录、不发送弹幕、不读取礼物榜。

在「平台连接」里用「启用 B站弹幕源」开关直接连接/断开；关闭只断开连接，不会清空房间号。也支持直接粘贴 `https://live.bilibili.com/6` 这类 URL。

B站 `getDanmuInfo` 需要 WBI 签名，适配器会自动从 `nav` 取密钥并生成 `wts` / `w_rid`，不需要手动填参数。

连接成功不代表一定有弹幕：状态栏会显示房间是「直播中 / 轮播 / 未开播」。未开播或轮播房间连接保持，但不会收到新弹幕；这是 B站侧的正常行为。

如果特定网络仍返回 `-352`，界面会显示「B站弹幕接口仍返回 -352」；适配器会先自动刷新 WBI 密钥重试一次。仍失败时换网络/稍后重试，或先用本地模拟完成演示。

### B站连接会发什么请求

连接一个房间时，只会发生这些**只读**请求：

| 请求 | 用途 |
| --- | --- |
| `GET room/v1/Room/room_init` | 房间号与 `live_status`（直播中/轮播/未开播） |
| `GET x/frontend/finger/spi` | 获取匿名 `buvid3/buvid4`，不涉及登录 |
| `GET x/web-interface/nav` | 获取 WBI 签名密钥 |
| `GET xlive/web-room/v1/index/getDanmuInfo` | 获取弹幕 token 与 WSS host |
| `WSS /sub` | 匿名认证 + 每 30 秒心跳 + 接收公开广播 |

不会发送弹幕、礼物、关注、点赞、分享、登录或任何 `POST` 写操作；不会使用 SESSDATA，也不会以你的账号身份进入直播间。

连接别人房间只会被动接收该房间的公开弹幕。它不是该主播的推流连接，不会改变对方的直播状态；单路连接对 B站弹幕服务器可以忽略。不要批量/高频连接，否则可能被 B站限流的是你的 IP，而不是主播。平台是否把匿名连接计入观看统计由 B站决定，本项目不伪造观看/人气。

## 5. 窗口位置

「设置 → 窗口位置」可以选择「跟随鼠标」「主显示器」或某一块具体显示器；选择后窗口立即移过去，并写入配置，下次启动继续使用。窗口没有系统标题栏，拖拽顶栏移动，右上角是自绘的最小化/最大化/关闭。

「设置 → 界面 → 直播间弹幕栏」可以选完整显示、折叠成窄条或隐藏；弹幕栏标题右侧也有收起按钮。隐藏后可在设置里恢复。

「设置 → 数据 → 清除所有数据」会弹出原生确认，确认后删除配置、历史和日志并自动重启。此操作不可撤销。

## 6. OBS

结果弹窗现在在控制台窗口内，不再有独立结果窗。

1. OBS → 来源 → 窗口采集 → 选择「互动工坊」主窗口。
2. 结果弹窗、彩带烟花和工具面板动画都在同一个窗口里，不需要为结果单独加采集源。
3. 结果弹窗可点右上角、遮罩或 Esc 关闭，不会自动消失。
4. 控制台本身包含侧栏和弹幕栏；如果只想要干净画面，后续可加「舞台模式」。

## 7. 数据与重置

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\interact-tools\config.json` | 平台与工具配置 |
| `%APPDATA%\interact-tools\history\dice.json` | 最近 20 条投掷记录 |
| `%APPDATA%\interact-tools\history\wheel.json` | 最近 20 条转盘记录 |

删除 `config.json` 后重启会恢复默认配置。「设置 → 打开数据目录」可以直接定位。

## 8. 打包

```bash
npm run package:win
```

产物在 `release/`。安装包与免安装版二选一。
