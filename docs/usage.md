# 使用说明

## 1. 运行

要求：Windows 10/11，Node.js ≥ 22.12。

```bash
npm install
npm run dev
```

首次运行会在 `%APPDATA%\interact-tools`（Electron userData）创建 `config.json` 和 `history/dice.json`。

如果 Electron 被当成 Node 启动（终端里出现 `Cannot read properties of undefined (reading 'requestSingleInstanceLock')`），先清掉环境变量 `ELECTRON_RUN_AS_NODE` 再运行：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm run dev
```

## 2. 本地模拟：先跑通全链路

1. 打开「平台连接」，确认「本地模拟」是「已连接」；没有就点「连接模拟源」。
2. 回到「控制台」，选骰子面数、倒计时、聚合方式。右侧实时弹幕栏在所有页面常驻，去「平台连接」或「设置」时也能看到观众在说什么。
3. 点「开始收集」。
4. 在右侧弹幕面板发送 `!力度 80`，或点「填充 8 条」让模拟观众投票。
5. 倒计时结束会自动投掷，骰子直接在左边的面板舞台里滚动；停稳后弹出原生结果小窗，带彩带烟花。看完点右上角关闭或按 Esc，不会自动消失。

模拟观众默认每 3 秒发一条消息，70% 是力度指令。可以在「平台连接」里关掉或调整间隔。

### 转转盘（主播手动）

1. 在控制台顶部工具切换器选择「转转盘」。
2. 在右侧编辑格子内容（每行一个，2–16 个），设置旋转时长。
3. 点「开始旋转」。主播手动触发，**没有弹幕命令、没有倒计时**。
4. 面板里的转盘原地旋转 5 秒后停住，结果格与顶部指针对齐；随后弹出原生结果小窗。
5. 「预览」不写入历史，用来调样式。

## 3. 命令

```bash
!力度 80
#力度 80
力度80
力度：80
POWER 60
```

- 值必须是 0–100 的整数；越界会被丢弃，不会截断。
- 同一观众在一轮里只算最后一条。
- 只认消息开头的命令，聊天里顺口说「力度」不算。
- 默认聚合是中位数；可在「聚合」里切换平均值 / 截尾均值。

## 4. B站

1. 在「平台连接」里填写直播间房间号（短号或真实房间号都可以）。
2. 点「连接 B站」。
3. 状态变为「已连接」后，弹幕会进入事件流；力度命令只在倒计时期间生效。

第一版是**匿名只读**：不登录、不发送弹幕、不读取礼物榜。

在「平台连接」里用「启用 B站弹幕源」开关直接连接/断开；关闭只断开连接，不会清空房间号。也支持直接粘贴 `https://live.bilibili.com/6` 这类 URL。

B站 `getDanmuInfo` 需要 WBI 签名，适配器会自动从 `nav` 取密钥并生成 `wts` / `w_rid`，不需要手动填参数。

连接成功不代表一定有弹幕：状态栏会显示房间是「直播中 / 轮播 / 未开播」。未开播或轮播房间连接保持，但不会收到新弹幕；这是 B站侧的正常行为。

如果特定网络仍返回 `-352`，界面会显示「B站弹幕接口仍返回 -352」；适配器会先自动刷新 WBI 密钥重试一次。仍失败时换网络/稍后重试，或先用本地模拟完成演示。

## 5. OBS

动画在控制面板内播放，控制台本身是给主播/场控看的；最终结果会弹一个原生小窗「1017 互动结果」。

1. OBS → 来源 → 窗口采集 → 选择「1017 互动结果」。
2. 小窗 680×480、透明、置顶；如果采集把透明区域变成黑色，勾选「允许透明」或加色度键。
3. 结果窗手动关闭（右上角 / Esc），不会自动消失。
4. 骰子和转盘共用这个小窗，不需要为每个工具单独加采集源。

如果希望把面板里的滚动/旋转也上屏，需要后续加「舞台模式」，当前版本不建议直接采集控制台。

## 6. 数据与重置

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\interact-tools\config.json` | 平台与工具配置 |
| `%APPDATA%\interact-tools\history\dice.json` | 最近 20 条投掷记录 |
| `%APPDATA%\interact-tools\history\wheel.json` | 最近 20 条转盘记录 |

删除 `config.json` 后重启会恢复默认配置。「设置 → 打开数据目录」可以直接定位。

## 7. 打包

```bash
npm run package:win
```

产物在 `release/`。安装包与免安装版二选一。
