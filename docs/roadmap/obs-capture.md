## 2. 目标与非目标

**目标**

1. 用 OBS 窗口采集控制台，确认弹幕、结果浮窗、彩带可见。
2. 在 Windows x64 安装包上完成安装/启动/卸载。
3. 记录失败现象与日志路径。

**非目标**

- 不验证所有 Linux 桌面环境。
- 不做自动更新。

## 3. 设计

- 以当前 `npm run package:win` 产物为对象。
- 采集源使用窗口采集，不加显示器采集。
- 结果弹窗、烟花、控制台背景分别截图。
